# Full Circle website

The product website for Full Circle, a daily wellbeing tracker for iPhone and Apple Watch.

## What the site covers

- Clear Full Circle positioning and App Store calls to action
- The five daily signals: daylight, mindfulness, exercise, headphone use and sleep
- Mood check-ins, positive moments, trends, correlations and weekly reflections
- Apple Health, Apple Watch, AirPods and Home Screen widget support
- Reviewer and press information with a direct contact route
- Search, Open Graph and structured application metadata
- Responsive, accessible layouts for mobile and desktop

## Local preview

The site is plain HTML, CSS and JavaScript with no build step. Open `index.html` directly or serve the repository with any static web server.

## Deployment

Deployment is configured for GitHub Pages from the root of `main`. The site is published at `https://fabriziodemaria.github.io/full-circle/`.

## Main files

```text
index.html   Page structure, product copy and metadata
styles.css  Visual system and responsive layouts
script.js   Header and reveal behavior
screenshots Product images and app icon
```

## Product link

App Store buttons use the stable application ID URL (`https://apps.apple.com/app/id6753870098`) so they continue to resolve if the App Store slug changes.
